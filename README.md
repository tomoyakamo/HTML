🔸PDS 10HzVer.
改良した点

更新頻度を10倍に: 1.0秒待ちだったものを**0.1秒（100ms）**に短縮しました。トントンという叩きに即座に反応します。

合成加速度 (Norm): Z軸だけでなく、X,Y,Z すべての揺れを合算して解析します。スマホをどの方向に叩いても反応します。

直流（重力）成分の除去: 静止状態の値をゼロにする処理を入れたので、揺れたときだけグラフに山が立つようになります。

ダークモード・ハイコントラスト: 現場での視認性を意識し、黒背景にグリーンの波形（古いオシロスコープ風）にしました。


追加した機能

「更新間隔」プルダウン: 計測中いつでも変更できます。

0.1s: 衝撃（トントン）の瞬間的な変化を見たいとき。

1.0s: 一定の周期で続く振動（機械の唸りなど）をじっくり観察したいとき。

縦軸の安定化: suggestedMax: 0.5 を設定し、小さなノイズでグラフが上下に激しく跳ねすぎるのを抑えました。

💡 現場での活用アドバイス

もし台車やモーターの振動をイメージされているなら、**「0.5秒」や「1.0秒」**に設定すると、突発的なノイズが平均化され、その機械が持つ「固有の周波数（山）」がはっきりと見えやすくなりますよ。
